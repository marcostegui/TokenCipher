# TokenCipher

Transfers encrypted data between devices using a secure, decentralized network protocol for peer-to-peer file transfers.

TokenCipher is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Transfers encrypted data between devices
- using a secure, decentralized network
- protocol for peer-to-peer file transfers

## Key Features

- Transfers encrypted data between devices

- protocol for peer-to-peer file transfers

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenCipher.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

TokenCipher is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
